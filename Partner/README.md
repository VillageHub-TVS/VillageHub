# Partner portal

This is a small JavaScript website served by Node.js. It has no third-party dependencies and does not use React Native.

## Run locally

Install Node.js 18 or newer, then from this folder run:

```powershell
npm start
```

Open [http://localhost:3000](http://localhost:3000). The server redirects to the overview page. Use `npm run dev` to restart the server automatically when its files change.

The listening port can be changed with the `PORT` environment variable.
